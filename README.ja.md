# Dialogue Memories

**思い出を話す。自分が物語の主人公になる。**

旅や日々の出来事、忘れたくない瞬間を、対話から読みものに育てるプラグインです。構成を考えてから話す必要はありません。音声入力でも、自分のペースで話し始められます。

[English](README.md)

## 普段はMemoryだけで

「旅の思い出を残したいけれど、何から話せばいい？」から始められます。自分の声で振り返る一人称も、ドキュメンタリーのように描かれる三人称も選べます。初稿を読んで思い出したことがあれば、話を続けて一篇に育てられます。

| スキル | 用途 |
|---|---|
| Memory | 旅行記・思い出・体験ルポ |
| Making | 迷いや決断を残す制作記 |
| Legacy | その人らしい声を残す人生の記録 |
| Fiction | 体験や着想から育てる創作 |

Memoryが普段の入口で、残る3つは違う形で書きたくなったときの選択肢です。4つを順番に使う必要はありません。

Making・Legacyは三人称を基本に、文章に使う呼び名を相談します。一人称にもできます。Fictionは一緒に発想を持ち寄ることも、展開を任せることもできます。感動や教訓を結末の条件にしていません。

## 0.1.0について

公開用のスキル本文は英語ですが、日本語で話し、日本語の文章を作れます。英語・日本語の依頼を使った限定試験を行っています。

OpenAI公式ディレクトリへの申請下書きを作成済みです。公開後に案内リンクを追加します。CodexへのGitHub経由の導入方法は[英語版README](README.md)にあります。

「Memories」は文章の題材を意味します。記憶の永続保存や会話の自動収集の機能はありません。開発者のサーバーへ会話を送る仕組みも含みません。会話の処理・保存には利用するアプリの設定やポリシーが適用されます。

文章を書くことと、その文章や元の対話を公開することは別です。共有する内容は本人が選びます。公開の問い合わせ欄に私的な会話や家族の情報を貼らないでください。[データの扱い](PRIVACY.md)もご覧ください。
